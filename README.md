# wet
Stream discharge for BC's Freshwater Atlas: monthly and seasonal flow per segment, historical and climate-scenario, from modelled runoff and hydrometric stations

[Flow in species windows at two stations](https://github.com/NewGraphEnvironment/wet/blob/main/vignettes/station-flow.Rmd) works through the station path on real data: the daily record by source, the hydrograph against its 1981–2010 median, departure per species window, and trends.
