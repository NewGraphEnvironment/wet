## Mechanism and enumeration

**Mechanism.** Both earlier findings are one move: a sentence restates a fact it took from a *neighbouring* artifact (what the code does in one place, how knowledge's note frames a date, the figure the sentence stands next to) and in the restatement its scope shifts by one step: a subject narrowed or widened ("the figures" for "the flow figures"; "a few visits" for "estimates"). code-check.md, "A guard's scope, escape hatches, and remedies", calls this compression running the unguarded way: "demoting evidence out of a rule can add a claim that was never there ... an attribution widened". The guards beside these sentences check a *number* in each (a date, a count) and never the *subject* the sentence gives it, so the shifted scope passes. The remedy is the one that section gives: read the source beside the restatement, both ways, and treat a sentence whose subject or quantifier changed as unsupported until the source holds it.
